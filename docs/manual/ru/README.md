# Руководство пользователя Sealbill

Sealbill — самостоятельно размещаемая система выставления счетов для тех, кто принимает криптовалюту, банковские переводы и платёжные ссылки одновременно и хочет хранить данные клиентов в зашифрованном виде. Руководство написано для тех, кто с ней работает: для сотрудников, выставляющих счета, и для того, кто её устанавливает.

Языки: [English](../en/README.md) · [Slovenčina](../sk/README.md) · [Čeština](../cs/README.md) · [Deutsch](../de/README.md) · [Español](../es/README.md) · [Français](../fr/README.md) · [Polski](../pl/README.md) · [한국어](../ko/README.md) · **Русский**

## Как читать скриншоты

- **Страницы для сотрудников** (всё, что находится за входом) всегда на английском, на каком бы языке ни говорил клиент. Названия меню и кнопок в этом руководстве записаны ровно так, как их показывает приложение.
- **Страницы для клиента** (страница счёта `/i/…`, страница оплаты `/p/…`, страницы платёжных ссылок, страница разблокировки и письма) переведены на en, sk, cs, de, es, fr, pl, ko и ru. Клиент видит язык контакта, затем язык организации, затем язык своего браузера; добавьте `?lang=de` к клиентской ссылке, чтобы увидеть её на другом языке.
- Все имена, адреса электронной почты, кошельки и суммы на скриншотах вымышлены: они взяты из демонстрационной организации «Example Studio s.r.o.» в одноразовой базе данных.
- Текст в `коде` — это то, что вы вводите или копируете. Команды записаны как `manage.py …`; в Docker Compose это `docker compose exec web python manage.py …`, под systemd — `payinv-manage …` (см. README репозитория).
