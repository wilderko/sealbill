Each language has the same ten files: a `README.md` (contents) and nine chapters, `01-getting-started.md` to
`09-api.md`. The screenshots are shared and live in [img/](img/). The staff pages are English in every language, because
the application does not translate them; the client pages (invoice, pay, payment link, unlock page, letters) are shown in
all nine.
